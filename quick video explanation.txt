swarm audio is a project which combines sensor data from multiple different smartphones being sent to a local server, where their individual motion sensors are being converted into advanced parameters. these parameters range from individual movement data to overall swarm parameters such as total swarm movement and energy, as well as movement coherence and diffusion. camera data is additionally processed for further controlling these individual clients which are also being rendered on an interface, offering an interactive environment.
all the data is transfered to a different computer which is acting as the audio host via OSC. there the indivdual clients control the voices of a simple polyphonic synthesiser, where pitch and 'roughness' of the individual voices is controlled by movement of the smartphone. these voices are then further forwarded into four instances of timbre transfer models using the neutone SDK, which can be switched on the fly, where granular modulation via all micro and macro parameters from the server is possible, but a default setup is provided.
this results in an embodied collective sound shaping experience, which is also fun.
